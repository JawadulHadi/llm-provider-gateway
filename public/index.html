llm-provider-gateway

A provider-agnostic LLM layer in TypeScript: retries with jitter, timeouts, a fallback chain, a circuit breaker, cost tracking and zod-validated JSON output. Source: GitHub.

The run below uses mock providers, so no model is called. The primary rate-limits on every try, the gateway backs off, falls back and opens the primary's circuit, the fallback answers in prose, and chatJson asks once for a repair and validates the result. Raw JSON: /api/demo.
